# Mockup de comportamiento

`Main.dc.html` es la fuente del prototipo navegable hecho durante el diseño: Dashboard, fichas, editor de tres modos, pistas y documentación.

No se abre directamente, porque necesita el entorno de Claude Design. Sirve como referencia de **lógica y flujos**: niveles de pistas, pistas graduales, cierre automático, enlaces y fichas calculadas desde el texto.

Su apariencia no es la definitiva. Para eso, ver `../ink-demo/` y `DESIGN.md`.

Ojo: la detección de nombres y las contradicciones del mockup son simuladas. No hay IA real.
