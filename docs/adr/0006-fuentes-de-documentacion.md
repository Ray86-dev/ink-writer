# 0006 · Fuentes de la documentación proactiva

**Estado:** aceptada.

**Decisión.** OpenStreetMap vía Overpass para calles y locales actuales; Open-Meteo para clima; búsqueda web del modelo con citas para lo demás. Se busca el tema, nunca al personaje.

**Motivo.** Una consulta estructurada no se inventa una cafetería. Un modelo sí puede hacerlo, por eso toda sugerencia necesita fuente.

**Consecuencias.** Open-Meteo gratis solo vale sin fines comerciales. Overpass público tiene límites por instancia. OpenStreetMap solo da el presente, así que la época es un dato del proyecto. La búsqueda se hace una vez por tema y se guarda.
